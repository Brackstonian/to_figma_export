# to_figma_export

Follow these steps to install:

### 1. Install Dependencies
`npm install` 

### 2. Build the Project
`npx webpack` 

### 3. Load the Plugin in Figma

-   Open a Figma File that you wish to export variables
    
-   In the menu bar at the top of the screen, go to `Plugins` > `Development` > `Import Plugin from Manifest`
    
-   Locate and select the `manifest.json` file from this repo
